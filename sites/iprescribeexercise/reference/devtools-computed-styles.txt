=== LAYOUT ===

Header: white background, logo wordmark left (two-tone: "STRENGTH" in dark
gray + "RUNNING" in brand blue), small uppercase tagline underneath, hamburger
icon + search icon right-aligned. No visible box-shadow on the header itself
in the sampled state.

Hero: large H1 headline, short underline/divider rule beneath it, then a
big hero image with an embedded intro video overlay (play button + captioned
label "Welcome to Strength Running").

Email opt-in block: appears early (First Name + Email inputs, stacked, full
width within content column) with a red "I'M IN!" submit button — full-width,
no border-radius visible (sharp corners), all-caps button label.

Search banner: full-width teal/blue bar with white search input and a prompt
line ("Need a running coach? Want a marathon training plan? Search our
content!").

Testimonials: "What Our Athletes Are Saying" section — circular avatar photo,
name in bold, italic pull-quote text above.

Program/course cards: repeated pattern throughout the middle of the page —
colored badge/logo image (own background color per program), bold headline,
1-2 line description, red "CLICK HERE" or "CHECK IT OUT" button. Each program
gets its own full-width card in sequence (Injury Prevention for Runners,
Bodyweight Power, High-Performance Lifting, Team Strength Running, Mindset
Mastery, etc.) — this is clearly a reusable card component repeated per
product/program.

Podcast section: light gray background, square podcast cover art, latest
episode list (title + date, thin divider between rows), "ALL EPISODES →" link.

Category pills: "Explore More Running Content" section — rounded pill-shaped
tags in a wrapped row (Strength Workouts, Form & Mechanics, Gym Workouts,
Injury Prevention, Marathon, Mental Toughness, Podcast, Recovery, Success
Stories, Training Design), plus a search box beneath.

Final CTA band: full-width photo background (runners) with dark overlay,
white body copy, red "GET YOUR FIRST LESSON →" button.

Footer: solid teal/blue background (#0492BF), white text, multi-column link
lists (Pages / Helpful Resources / Courses & Coaching), social icons row
(circular white-outline icon buttons), centered copyright + "SITE DESIGN BY"
credit line at the very bottom.

=== INTERACTIVE ELEMENTS ===

Mobile/compact nav: hamburger icon toggles a full-width teal (#0492BF)
dropdown panel directly under the header, white uppercase-ish link list
(About, Blog, Coaching, Deals, Podcast, Join SR, ...). Toggling again (icon
becomes an X while open) closes it. No animation duration/easing captured —
transition appeared instant/fast in this environment; verify against the
live site again before assuming a specific timing if it matters to the build.

Search overlay: clicking the magnifying-glass icon replaces the header-area
content with a full-bleed teal (#0492BF) overlay containing a centered
"Search..." input (white text/placeholder, underline-style field, no visible
box) and a close (×) icon top-right of the input row.
