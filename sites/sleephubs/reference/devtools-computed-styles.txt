LAYOUT
====================
- Header: position sticky, background white/transparent, subtle shadow
  `0 2px 8px rgba(0,0,0,0.06)` on scroll.
- Nav: horizontal link row (Best Mattress / Mattress Reviews / Accessories /
  Sleep Resources) each with a chevron-triggered dropdown, search icon at
  far right.
- Hero: full-width dark navy section with wavy bottom edge (SVG divider),
  centered white H2 + subtext + single orange pill CTA button.
- Content sections alternate white and light-gray backgrounds, each with an
  eyebrow label (small orange uppercase text) above a large navy H2.
- Cards: white background, rounded corners, icon + heading + short copy +
  "Learn More" link — used repeatedly for topic clusters (Mattress Reviews,
  Mattress Comparisons, Mattress Information, etc.)
- Grid sections (mattress type, pain relief, sleeper type, accessories):
  4-column card grid on desktop, image + label per card.
- Footer: dark navy background, logo + social icons row, 3-column link
  list (Sleep Solutions / Sleep Topics / About Us), two pill buttons
  (Mattress Comparison / Buyer's Guides), copyright + disclosure text below
  in a lighter/muted tone.

====================
INTERACTIVE FEATURES
====================
- Nav dropdown (desktop): clicking a top-level nav item (e.g. "Best
  Mattress") opens a full-width mega-menu panel below the header —
  multi-column list of links with chevron icons, white background,
  box-shadow `0 1px 2px rgba(0,0,0,.25), 0 0 1px rgba(0,0,0,.35)`,
  overlays page content rather than pushing it down. See
  homepage-interactive-01-nav-dropdown.jpg.
- Search (desktop): clicking the search icon expands an inline bar directly
  below the header (search input + orange "SEARCH" button + "Close Search"
  link) — not a modal/overlay. See homepage-interactive-02-search-bar.jpg.
- Mobile header: nav collapses to logo + hamburger icon under ~600px viewport
  width. See homepage-mobile-01-header-hamburger.jpg.
- Mobile drawer: hamburger opens a full-screen white overlay — search input
  at top, accordion-style nav list (chevron per item, expandable), a second
  search bar repeated near the bottom, and a close ("X") icon top-right
  replacing the hamburger. See homepage-mobile-02-drawer-open.jpg.
